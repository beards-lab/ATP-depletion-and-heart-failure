# Problem Summary

## 1. Nature of the Model

-   Deterministic mechanistic model
-   \~10 true physical state variables (core physics)
-   Additional tens to \~100 states due to spatial discretization of
    some physical variables
-   All model states are observable

This means the system is:

> Low-dimensional physics embedded in a high-dimensional numerical
> representation.

------------------------------------------------------------------------

## 2. Core Issue

The mechanistic model does not match experimental or reference data
well.

The suspected cause is:

-   Missing or incorrectly modeled physical mechanism
-   Structural model error (not just parameter mismatch)

------------------------------------------------------------------------

## 3. Available Information

Approximately 12 extracted behavioral features, such as:

-   Peak characteristics
-   Increase and decay rates
-   Combinations of response patterns
-   No simple overshoot-type signatures

These features reflect complex dynamic behavior rather than a single
obvious missing effect.

------------------------------------------------------------------------

## 4. Main Goal

The primary objective is:

> Understanding the missing physics.

This means:

-   Interpretability is required
-   Mechanistic insight is the goal
-   Pure black-box correction models are not sufficient

------------------------------------------------------------------------

## 5. Key Difficulty

The challenge arises because:

-   The system is spatially distributed
-   Spatial discretization inflates the state dimension
-   Complex behavior obscures structural interpretation

The central question becomes:

> What methodology can systematically guide the discovery of missing
> physics in a spatially discretized mechanistic model?

------------------------------------------------------------------------

## One-Sentence Description

Identifying missing physics in a spatially discretized deterministic
mechanistic model by analyzing structured discrepancies between model
predictions and observed system behavior.
